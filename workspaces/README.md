# Workspaces

Workspaces are isolated knowledge sandboxes for projects, products, teams, or domains.

The release package includes the `default` workspace as a starter seed library. Additional workspaces are intentionally local by default so private project context does not get packaged or committed accidentally.

Use `agentctx init --knowledge-root <path> --workspace <name>` to point a codebase at the workspace it should use.
